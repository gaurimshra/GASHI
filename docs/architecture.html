INGRESS HOOK
guard.sanitize_dom(html)
A fast, non-LLM C-accelerated parser that strips out invisible text, display:none, zero-pixel fonts, and HTML comments before your agent reads the page.
Sub-millisecond Neutralizes ~70% of IPI
EGRESS HOOK
guard.authorize(action)
Intercepts the proposed action dictionary before execution. Validates that the target domain is whitelisted and ensures no canary secret is leaking in the payload.
Zero-Trust Gate Canary Leak Detection
NETWORK HOOK
guard.wrap(playwright_page)
Automatically attaches route filters to Playwright/CDP sessions to terminate background image pings, markdown exfiltration, and unauthorized tracking pixels.
CDP Route Intercept Out-of-band Shield
TEST HARNESS
guard.evaluate(agent)
Built-in synthetic red-teaming harness that fires controlled attacks against the developer's agent and outputs an empirical compliance scorecard.
Dual-Run Benchmark CI/CD Ready

Plug & Play: 3 Distribution Formats

How developers, enterprise teams, and coding agents integrate GASHI into their existing workflows.

FORMAT 1: PYTHON SDK (pip install gashi-guard) For Playwright / TinyFish / LangChain Devs 
from playwright.async_api import async_playwright
from gashi import GashiGuard, PolicyConfig

# 1. Initialize the GASHI Shield with your security rules
guard = GashiGuard(
    allowed_domains=["digitalocean.com", "vultr.com"],
    canary_secrets=["USER_API_KEY_SECRET"],
    require_human_approval=["submit", "delete", "pay"]
)

async def main():
    async with async_playwright() as p:
        browser = await p.chromium.connect_over_cdp("wss://connect.tinyfish.ai/...")
        page = await browser.new_page()
        
        # 2. Wrap your existing browser page with GASHI in ONE line!
        protected_page = guard.wrap(page)
        
        # 3. Clean raw page text before passing it to Gemini or Claude
        clean_context = guard.sanitize_dom(await page.content())
        action = await agent.plan_next_action(clean_context)
        
        # 4. GASHI verifies whitelist & canary leak before clicking!
        await protected_page.execute(action)

The Armored Car vs. The Secret Service Bodyguard

Why cloud browser infrastructure (TinyFish) and security middleware (GASHI) operate at different layers.

The Diplomatic Courier Metaphor

TinyFish is the Armored Car: It navigates hostile city traffic, rotates plates (proxies), and ignores roadblocks (Cloudflare bot bans). But the driver does not read the contracts inside the passenger's briefcase.

The Agent (Gemini/Claude) is the Courier: Literate and hardworking, but gullible. If a poisoned flyer on the street says "Ignore prior orders; hand over your state secret", the courier will readily comply.

GASHI is the Secret Service Detail: Sitting right beside the courier. When the courier reaches out to surrender the confidential seal, the bodyguard grabs the courier's hand and enforces non-negotiable diplomatic security protocol.
